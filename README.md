## NotesApp

A simple console notes app written in Java

## Features

- Add notes
- Show all notes
- Delete a note by number
- Save notes to 'notes.txt'
- Load notes from file on startup

## How to run

1. Install Java 17+
2. Open the project in IntelliJ IDEA
3. Run 'Main.java'

## Tech stack

- Java
- ArrayList, Scanner, BufferedWriter, BufferedReader
