# NotesApp

Консольное приложение для заметок на Java.

## Что умеет

- Добавлять заметки
- Показывать все заметки
- Удалять заметки по выбранному номеру
- Сохранять заметки в файл 'notes.txt'
- Загружать заметки из файла при запуске

## Как запустить

1. Установить Java 17+
2. Открыть проект в IntelliJ IDEA
3. Запустить 'Main.java'

## Стек

- Java
- ArrayList, Scanner, Bufferedwriter, BufferedReader
